### Summary of Project:
It should become a video chatting app I can host with my friends.

### Instructions:
1. I do not want you to code any of the application code. At best you can write tests that I need to pass.
2. I want to learn how to code in Rust.
3. I want to learn real-time compression algorithms to make the application performant.
4. I want to allow my friends to login through SSO providers.
5. I want to learn how to develop a video chatting app from start to finish.

### Application Details:
- Google and Facebook as the preferred SSO providers.
- For the protocol stack use WebTransport with QUIC.
- For the frontend I would like to first target a web frontend, and then target a native Rust desktop GUI.
